# 风轮时 (FengLunShi)

专为老旧安卓设备（以及现代安卓设备）设计的纯黑桌面/床头数字时钟 App，**零第三方库依赖**，安装包仅约 **145 KB**，原生适配 **Android 4.0 (API 14) ~ Android 14 (API 34)**。

- **包名**：`com.fenglunshi.clock`
- **最低系统**：Android 4.0 (Ice Cream Sandwich, API 14)
- **目标系统**：Android 14 (API 34)

## 核心功能

- **逐字流光彩虹渐变 & 纯黑底色**：
  - `#000000` 纯黑背景，省电护眼；支持 OLED 防烧屏每分钟微移保护与夜间亮度调节。
  - 原生 `LinearGradient` 动态流光渲染，每个数字内部呈现多色渐变过渡。
  - 内置 5 套流光色系（流光彩虹、北极光、日落霓虹、赛博朋克、自定义双色渐变）、24 小时昼夜色温渐变以及自定义纯色（RGB 滑块实时预览）。
- **整个时钟布局自由自定义**：
  - 对齐方式（居中 / 左对齐 / 右对齐）、时间排列（横向 `HH:mm` / 上下堆叠大字）、字号缩放（`60% ~ 135%`）、4 种字体风格、日期位置（上方/下方/隐藏）、天气位置（主区域/四角/隐藏）、元素间距。
- **角落日程倒计时**：
  - 可置于屏幕任意角落，自定义日程标题与目标日期时间（附快捷预设），大于 1 天显示 `XX天 XX时XX分`，24 小时内精确到秒。
- **当地天气显示**：
  - 自动 IP / 系统定位获取当地温度、天气、今日温差与湿度，每 30 分钟刷新。
  - 针对老旧 Android 4.x 根证书过期问题内置 **HTTPS → HTTP 自动回退**，支持 16 个常用城市速选及自定义城市搜索。
- **整点语音报时（系统 TTS + 内置清脆钟声）**：
  - 优先调用安卓系统自带中文 TTS 语音报时，并内置纯代码 `AudioTrack` 合成的三音阶清脆钟声（无 TTS 引擎时自动回退，100% 离线可用）。
  - 支持整点/半点报时、夜间免打扰静音时段、后台保活报时与一键试听。
- **横竖屏自由切换**：一键切换横竖屏，并支持自动感应、锁定横屏、锁定竖屏、锁定反向横屏。
- **后台保活、自启动、悬浮窗与无障碍**：
  - 前台常驻保活服务 + 开机自启动 + 可选充电自动打开时钟。
  - 支持引导申请悬浮窗权限（内置可拖动纯黑悬浮迷你时钟）与无障碍保活辅助服务（不读取任何屏幕内容）。

## 下载安装

直接前往本仓库右侧 **Releases** 页面下载已签名的 `风轮时-v1.0.0-api14.apk`（已同时启用 v1 + v2 签名，可直接安装到 Android 4.0 及以上设备）。

## 本地编译构建

### 方式一：一键脚本直接编译签名（无需下载 Gradle）
```powershell
powershell -ExecutionPolicy Bypass -File .\build_apk.ps1
```
产物输出至 `build_out\风轮时-v1.0.0-api14.apk`。

### 方式二：Android Studio
直接用 Android Studio 打开本项目目录，Sync 后点击 Build APK 即可。
